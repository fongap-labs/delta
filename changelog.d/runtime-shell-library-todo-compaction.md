- 新增: 资料库是 Delta 的语料来源库——一个由用户自定义位置的文件夹，存放纯 Markdown 与文本语料（类似 NotebookLM 的"来源"）。侧栏在"自动化"下方新增"资料库"入口；页面列出文件夹中的来源（名称、大小、修改时间），可内联编辑、新建与删除，文件夹位置可通过系统目录选择器随时更改（由 Rust 权威持久化；默认位置在状态目录下，首次运行即创建）。文件名校验拒绝路径穿越与非托管扩展名，前端不直接触碰文件夹。
- 新增: 模型可在对话中使用资料库。能力宿主新增两个低风险免审批工具：`search_library` 在语料中查找匹配行并给出来源文件名（大小写不敏感、单次有界、跳过大文件），`read_library` 按名读取单个来源（有字符上限并带截断标志）。与资料库页面一起完成语料闭环：用户维护来源，模型检索与读取以支撑回答。
- 新增: `todo_write` 成为真实工具。桌面界面一直从工具提议事件渲染模型的任务列表，但后端从未注册该工具（旧 Python 集成模块是死代码）；Rust 能力宿主现在注册一个纯规范化器：校验列表、兼容旧 `items` 键与 `completed` 状态别名，并回显规范列表。低风险、免审批。
- 新增: 模型可在对话中用 `create_scheduled_task` 创建自动化。一次经批准的调用在 Rust 自动化权威中建任务：计划经过校验（五段 cron 或 RFC 3339 单次时间；永不触发的计划被拒绝而不是归为手动任务），可选时区、工作区与无人值守运行的常驻权限。工具自身不携带任何授权，与其他 automation 类工具一样需批准。
- 新增: 长对话自动压缩上下文。请求前估算上下文达到 `min(threshold_pct × 上下文窗口, cap)` 时，运行时请模型把除系统提示与最新用户输入之外的内容总结为摘要，此后以摘要替代被折叠的历史发送，并把摘要与会话一起持久化，重新打开的会话继续基于摘要工作。会话记录本身不改写，边界索引跨重启有效，摘要请求与其他模型请求一样经过出站门禁；阈值、Token 上限与摘要模型可在 General 设置（`compaction_threshold_pct`、`compaction_cap_tokens`、`compaction_model`）配置。
- 新增: `run_shell` 工具运行一条经本地批准的 shell 命令并捕获退出码、stdout 与 stderr。经能力宿主注册并声明高风险与破坏性副作用，策略层把每次调用都置于批准之后；"始终允许"只保存精确的命令串，绝不放行整个工具。运行器只继承操作系统引导环境变量（外加 `PATH`，以便按名解析 git、uv 等工具），Windows 上无控制台窗口，非零退出码作为完成结果报告，同时遵守任务超时与运行时取消。
- 变更: 侧栏主导航第一项由"对话"改为"新对话"；右侧栏移除"完整记录见『审计与溯源』"页脚行。
- 修复: `retry.rs` 移除镜像 Python 的死代码（`classify_error`、`ErrorClass`、`RetryClassifyInput/Output`）与关于已不存在的 Python 重试层的叙述——运行时只使用分层裁决（`is_retryable_failure`、协议与工具拒绝探测器），模块文档随之一并更新。
