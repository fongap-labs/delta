# Delta 品牌资源

本目录独立保存 Delta 首版所用的品牌源文件；构建不引用旧版本目录。

来源：fongap-labs/delta `legacy/delta-v0.0.1`，提交 `d9eb5531b4b708a96c0874712b3205be29741e73`。按 Delta 品牌治理由产品权利人授权使用。

- `delta-logo-512x512.png`：Logo 主资源。
- `delta-logo-256x256.png`：同一 Logo 的小尺寸副本。
- `delta.ico`：该仓库同版本已经生成的 Windows 图标，用于应用、窗口和托盘图标。

该分支未提供名为 splash/startup 的启动画面素材。首版启动画面将使用本目录的 Logo，在 Delta 自有界面绘制；不调用登录页或远程页面。
