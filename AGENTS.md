# Agent Guide

Read [README.md](README.md) for the project's current scope and instructions.

## Shared governance

Follow the applicable [Fongap Labs shared governance](https://github.com/fongap-labs/action-worker/blob/main/docs/01_SHARED_GOVERNANCE.md). Keep product rules here and refer to Action Worker for organization-wide rules.

## Commit messages

- Follow the organization’s required format for commit titles. Every non-empty Git commit body must use Chinese for its natural-language explanation; preserve technical identifiers, paths, and commands verbatim. See the [changelog conventions](https://github.com/fongap-labs/action-worker/blob/main/docs/04_CHANGELOG_CONVENTIONS.md).
