# Delta Worktree 基础模块

此模块使用用户本机 Git 创建独立的分离 HEAD 工作目录。会话适配器通过 Host 的工作目录服务提交切换，并提供 `/worktree create <task>`、`/worktree enter <task>` 和 `/worktree leave` 命令。产品配置默认关闭，用户须主动启用 `delta-worktree` 插件；配置根目录位于 Delta 数据目录。

目标目录必须位于仓库外的 Delta 管理目录。底层清理前检查跟踪、未跟踪和忽略文件；存在内容变更时拒绝删除。清理尚未实现跨会话占用保护，故命令不提供删除操作。原仓库路径未改变时，重新进入已搬迁的便携数据目录会修复 Git 关联；若原工作目录仍然存在则拒绝自动切换。原仓库同时搬迁的恢复及桌面成品操作仍需验收。
