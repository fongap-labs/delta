# Delta sidebar branding

English | [中文](README.zh.md)

This package fills the Client sidebar mark and name slots with Delta's own logo and product name. The logo is stored in this package's source tree so builds do not depend on the legacy Delta checkout. The desktop welcome page and native application icon use the matching copies under `apps/desktop/`.

The package retains its upstream package identity for first-release compatibility with the Harness profile loader. Delta owns its current source changes and can replace this compatibility point when the profile composition is migrated.
