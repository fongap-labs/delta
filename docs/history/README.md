# 历史与兼容资料

本目录是历史资料的检索入口，不将旧行为、旧版限制或原始决策记录提升为现行规范。

## 资料入口

- [持久化与历史格式](../persistence-changes/README.zh.md)：已发布数据格式及兼容变更。
- [事故复盘](../postmortem/README.zh.md)：问题经过、证据和修复背景。
- [升级指导集合](https://github.com/fongap-labs/delta/tree/main/docs/upgrade-guide)：逐版本升级和破坏性变化。
- [Agent 决策记录](../../.agents/notes/README.md)：设计理由与归档资料。

## 归档原则

优先保留已发布版本的数据迁移证据、版本约束与可验证的历史记录。归档不意味着可直接删除：修改旧文件前需要检查生成器、链接、当前协议与升级读者。现行产品行为请以 [架构](../architecture/README.md) 和 [技术参考](../reference/README.md) 为准。
