# AGENTS — Documentation

- Follow the root AGENTS.md. These rules apply only to documentation; they do not authorize exceptions to central engineering governance.
- Document current behavior at its owning location. Architecture belongs in architecture.md, subsystem types and semantics in subsystems/, package contracts in package READMEs, design rules in core-guidelines/, defensive rules in defensive-patterns/, procedures in cookbook/, incidents in postmortem/, and user guides in user/. Delta-specific decisions belong in docs/delta/. Link to the owning document instead of duplicating its contents. Do not resurrect retired upstream Agent Notes or skills.
- A tutorial follows an ordered path from prerequisites to a concrete result. A reference defines a lookup scope and current behavior. Separate the two when substantial. Keep detail at the owning level; higher-level documents describe child responsibilities, not their implementation.
- Use one physical line per prose paragraph. Preserve code, tables and list structure. Use direct terminology, concrete actors and contracts. Do not repeat generated catalogs, JSDoc, test walkthroughs, rejected alternatives or implementation-status announcements. Comments and JSDoc follow the root necessity rule.
- Update the owning subsystem reference with documented type changes. Maintain compilable TypeScript examples and registered type-equiv/public-api fences; regenerate generated references rather than editing generated English regions by hand.
- Update existing bilingual documentation pairs together according to i18n/README.md; preserve terminology and unchanged text. Do not create unnecessary translations or duplicate guides.
- Use relative links for current files and tags or PR numbers for historical references. Verify links and repository references using existing checks. Historical incident and persistence records retain their evidence scope.
- Existing non-AGENTS documentation budgets remain defined in scripts/doc-budgets.manifest.json. Relocate or condense content first; justify a budget increase if necessary. AGENTS.md has no size limit. Do not lower required coverage to meet a length target.
