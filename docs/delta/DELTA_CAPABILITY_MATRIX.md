# Delta 首版能力与验证清单（工作稿）

> 状态：用于盘点和验收设计；“保留目标”不代表已经实现或测试通过。上游来源 `4b399c39a6d1479cd84ca591b4d7c88e24d38a96`。

## 已确定的首版基础

Windows x64 便携版，发行根目录包含 `App/`、`Data/`、`Other/`。Delta 管理的用户数据应使用 `Data/`；目录及外部组件的实际行为须经过验证。默认本地优先，文档中文，第一方界面简体中文和英文。DeepSeek 官方账号登录可选，失败不阻断首发，不影响用户自行配置支持的模型。

| 能力 | 产品目标 | 首版验证示例 |
|---|---|---|
| 智能体和模型 | 保留对话、实际模型请求、流式响应及任务执行 | 真实模型响应、取消与失败恢复 |
| 计划、工作流、子智能体 | 保留原评审稿列明的核心能力 | 在批准的范围内完成代表性真实任务 |
| 工具、终端和权限 | 保留文件、命令等工具及权限边界 | 允许、拒绝、取消、路径与异常处理 |
| 会话与工作区 | 持久化、附件、恢复、上下文压缩 | 退出、移动便携目录、重启后恢复；迁移与损坏处理 |
| 插件、MCP、Skills | 保留原生协议和已批准的管理与扩展能力 | 代表性插件的安装、启停、卸载与重启；MCP 注册和取消 |
| Desktop 与 CLI | 保留桌面及首版经核实的 `delta` 命令 | 打包启动、基本命令、退出码以及与 `dsh` 共存 |
| 鉴权 | 可选官方账号；保留批准的模型鉴权方式 | 未登录仍可使用用户配置模型；官方登录实际验证，失败可受限 |
| 语言 | 界面语言由应用设置决定，首版为简体中文/英文；会话回复语言独立跟随用户表达或明确指定 | 两种界面语言及覆盖持久化；交叉验证“中文界面+英文会话”和“英文界面+中文会话”；工具状态/审批/错误本地化；切换语言不改写旧消息；模型回复语言行为 |
| 隐私与本地数据 | 移除禁止的第一方遥测和反馈上报入口 | 文件、装配、产物、代表性网络与凭据检查 |

## 首版保留的五项产品能力

| 能力 | 简要用途 | 已确认的处理方向 | 需核查 |
|---|---|---|---|
| CUA | 在授权下观察和操作本机应用窗口、键盘和鼠标 | 保留 | 非实验来源或自研；验证 Windows 授权、窗口观察和操作 |
| 浏览器操作 | 观察和操作网页 | 保留 | 非实验来源或自研；验证浏览器提供方、页面操作和权限 |
| Forge | 与 GitHub/GitLab 代码托管平台交互 | 保留 | 非实验来源或自研；验证 GitHub、GitLab 接入和认证 |
| Worktree | 为会话使用独立 Git 工作目录 | 保留 | 非实验来源或自研；验证创建、切换、隔离和清理 |
| LiveShare | 分享会话并管理访问范围 | 保留 | 非实验来源或自研；验证服务、访问授权和撤销 |

产品能力继续保留，但不直接吸收 Harness 处于实验状态的功能实现。上游固定版本中，这五项的部分实现或提供方属于实验范围；可用的替代来源、实现成本和可行性均待验证。不得通过重命名上游实验代码规避要求，也不能在替代方案未实现时声称功能已可用。默认关闭或由用户主动启用。

## 范围与证据

“保留 Harness 核心能力”以实际功能和验收结果表达，不原样吸收遥测、官网、官方发布体系及处于实验状态的上游功能实现。形成最终白名单前，需要从固定版本的包清单、Cordis 动态装配、资源、原生依赖和产品体验共同核对，审查删除上游实现与保留产品能力的交集。
