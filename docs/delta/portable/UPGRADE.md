# Delta 便携版升级与数据保护

本指南适用于 Delta Windows x64 便携发行目录。首次发行不提供从 Harness 或旧 Delta 自动迁移的承诺，也不要求卸载同机 Harness。

## 首次安装

将发行包完整解压到新的可写目录。不要将 Harness 的 Home 或其他应用数据目录直接指定为 Delta 的 Data。先用新的 Data 验证应用启动、CLI、所需配置和工具权限，再引入工作数据。

## 更换 Delta 发行版本

1. 退出 Delta 及其后台进程，保留当前完整便携目录的备份。Data 可能含凭据，备份应保存在受控位置。
2. 将新版本解压到单独目录，检查 Other/VERSION.json 与发行版本是否一致，并核验 SHA256SUMS.txt。
3. 优先用空 Data 启动验证；如需复用旧数据，仅在已确认目标版本支持相应格式时，使用旧 Data 的副本验证配置和会话读取。不要直接覆盖唯一原始数据。
4. 验证失败时退出新版本，重新启动未修改的旧备份。若新版本已写入数据，不应在没有兼容性证据的情况下把新 Data 覆盖到旧版本。

当前首版没有经验证的跨版本自动升级、数据格式降级或自动迁移保证。每个后续发行如引入格式变更，应提供该版本的迁移条件、备份及回退说明。
