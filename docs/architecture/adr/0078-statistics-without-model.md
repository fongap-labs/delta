# ADR-0078：统计工具无需 AI 网关即可运行，并新增 f2

状态：**已接受**（所有者，2026-10-26，同意"没有网关时也能运行 DOE、f2 等统计分析工具"；f2 作为 Foundation 的免费功能）。

## 背景

- 统计工具（描述统计、检验、回归、DOE、ANCOVA、货架期）在能力表中启动时即注册，计算由本机 R 完成，不经网络。
- 但产品中只有模型回合能调用它们。每个回合都要先解析模型配置（`start_runtime_with` 中的 `resolve_runtime_config`），没有配置 AI 网关时对话无法开始，统计工具也就无法被调用。
- `invoke_capability` 的 UI 白名单只包含浏览器工具。它绕过了策略层，不能为统计工具放宽。

## 决定

1. **新增不经过模型的运行入口。** `CoreControlPlane::run_statistics_tool` 只接受满足以下全部条件的能力：
   - 能力标识以 `statistics.` 开头；
   - 副作用为 `None` 或 `Read`；
   - 没有网络、密钥、进程或写入授权；
   - 不写工作区。

   它仍然通过能力宿主执行，执行门（execution gate）照常生效。它跳过的只是模型回合，不是策略检查。模型路径里与审批、出境档位相关的检查，对只读的本机计算不适用。

2. **桌面端提供"统计"页面。** 工具列表与表单由各工具的 JSON Schema 生成，数据文件从当前会话所在的工作区读取。页面不计算任何数值。

3. **新增 `statistics_f2`（Foundation，免费）。** 输入两列各时间点的平均溶出百分数（参考制剂与受试制剂），R 计算

   f2 = 50 · log10(100 / √(1 + 均方差))

   输出 f2、时间点数、均方差、最大差值，以及两个制剂各有多少个平均值超过 85%。

## 修订（2026-10-27，依据 ADR-0080 第 2 节）

ADR-0081 移除了 R 统计，`statistics_f2` 因此不再注册。统计页的工具改由 Explore 运行时提供，本节修订第 1 条的进程授权规则：

1. 无模型入口允许进程授权（`exec`）**仅限** `statistics.explore.*` 工具：它们运行一个由配置固定的 Python 运行时（`DELTA_EXPLORE_PYTHON` 指向解释器，`DELTA_EXPLORE_ROOT` 指向包含 `packages/explore_pack/worker.py` 的仓库根），以 `python -I` 启动，无网络、无密钥、无写入根。其它统计工具仍不得申请 `exec`。
2. 两个环境变量必须指向存在的文件；否则不注册任何统计工具，统计页保持为空，不回退到其它引擎。
3. 这些工具只产出 `exploratory` 结果；正式报告门禁照常拒绝它们（`numeric_trace/report.rs`）。
4. 当前提供四个工具：描述统计、Welch t 检验、Pearson 相关、简单线性回归。
5. 运行时的分发、签名与三平台构建仍未决（ADR-0080），本修订不解决它。

## 不做什么

- 不检查 f2 的适用条件（至少 3 个时间点、每个产品至多一个平均值超过 85%、单位变异限度）。这些只在输出中报告，由使用者判断是否适用。
- 不把统计结果写入 Suite 的报告；Suite 仍须通过 Foundation 的公开接口取数（`docs/domains/pharma-cmc.md` §2）。
- 不开放写入类统计工具（`statistics_record`、`chart_render`）给无模型入口，它们是 `LocalWrite`。

## 验证

- `delta-core` 单元测试：只列出只读的统计工具；拒绝 `run_shell`、`statistics_record` 和未知工具；空工作区被拒绝；f2 的闭合式结果（R = 10、40、70，T = 12、38、75，f2 = 73.02046884880939）。
- R 相关的测试在没有 R 的环境中直接返回，需要 CI 中的 R 4.6.0 才会真正执行。
- 前端：`StatisticsView` 的表单、运行、错误与无工作区三种状态的测试。

## 后果

- 没有网关时，用户可以在界面中运行统计计算，但不能撰写或分析结果。
- 新增的入口是一个产品面，需要在审计中记录统计运行（尚未实现，见待办）。
