# ADR-0072：Suite 首批功能：稳定性货架期、溶出 f2 与报告模板

状态：**已接受**（所有者，2026-10-26，同意首批范围与参数策略）。

## 背景

- 蓝图 §6.3 规定行业能力放 `delta-suite`，只通过公开契约接入。ADR-0071 把 CMC 专用内容划给 Suite。
- ADR-0071 之后，首批确定为三项：稳定性货架期估计、溶出曲线 f2 比较、稳定性报告模板与校验规则。
- 所有者提出的问题：货架期与 f2 的计算依据是否由用户输入。

## 决定

### 1. 范围

| 功能 | 内容 | 依赖的基础版能力 |
|---|---|---|
| 货架期估计 | 对稳定性数据拟合回归，按单侧置信界限估计货架期；检验批次能否合并（poolability） | 回归、数字溯源（ADR-0055） |
| 溶出 f2 比较 | 计算 f2 相似因子，画两条溶出曲线对比图，检查时间点是否满足比较条件 | `chart_render`（ADR-0070） |
| 稳定性报告模板与校验规则 | 报告中的数字全部用绑定写入；校验规则检查报告是否覆盖常见口径 | `report_render`、`report_check` |

第二批（设计空间、混合设计、SPC、行业图表与技能）不在本 ADR 范围内。

### 2. 参数策略

算法固定，参数分三类：

| 类别 | 内容 | 规则 |
|---|---|---|
| **算法固定** | 回归模型形式、f2 公式、poolability 检验方法、结果字段 | 代码内固定、版本管理；用户不能提供公式 |
| **可调整参数** | 单侧置信水平、poolability 的显著性水平 | 允许调整；每次调整必须记录理由，并在报告中标注 |
| **锁定参数** | f2 通过阈值（默认 50）、最少时间点数 | 默认锁定；修改需要方法负责人批准，并记录批准人 |

用户输入只限于：数据文件、批次列、时间点、规格限，以及可调整参数。

### 3. 结果记录

每次计算的结果文件都要包含：算法版本、所有参数及其来源（默认值或调整值）、调整理由、输入文件哈希、R 版本、绘图或计算程序哈希。偏离默认值的结果，报告模板必须输出标注。

### 4. 实现方式

- 计算放在 Suite 的 R Worker 中，R 版本与基础版的固定版本一致（4.6.0），由 Suite 的清单声明。
- Suite 只通过公开契约接入：清单、Worker 协议、结果文件格式（ADR-0055）。不导入基础版的内部模块。
- 默认值的依据必须由方法或质量人员对照指南原文确认后，才能写入代码。

## 后果

- 首批三项的默认参数在没有确认前，不能用于正式报告。
- Suite 的清单格式需要先按 `OPEN_ITEMS.md` §4 补齐 schema 与 ABI 声明。

## 未验证事项

- **默认值与指南的一致性未核对。** 本 ADR 没有联网核实指南原文，f2 阈值、poolability 显著性水平等数值需要由质量人员确认。
- **算法未与参考结果对照。** 货架期与 f2 的输出需要用公开的参考数据逐项核对。
- **未做 IQ/OQ 验证。** 如用于受监管的工作，需另外执行（见 ADR-0071 与对话中的说明）。
- **Suite 仓库未接入。** `fongap-labs/delta-suite` 目前不在本会话的授权范围内，实现前需要写入权限。
