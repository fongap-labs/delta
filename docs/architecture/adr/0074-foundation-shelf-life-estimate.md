# ADR-0074：基础版统计引擎计算预测置信界限与有效期

状态：**已接受**（所有者，2026-10-26，同意把第二个缺口放进 Foundation）。

## 背景

- ADR-0072 的稳定性有效期功能需要两类数字：(1) 随时间变化的属性均值及其单侧置信界限；(2) 置信界限越过接受标准的时间点，即有效期。
- 现状（已核对）：`statistics_regression` 给出系数与标准误，但不给出某个时间点上的预测均值置信界限，也不求解越界时间。
- `docs/domains/pharma-cmc.md` §2 规定：可报告数值必须由 Foundation 的统计引擎计算，Suite 不能在引擎之外推算。因此这两类数字必须由 Foundation 计算。

## 决定

在 Foundation 新增工具 `statistics_shelf_life`，它是通用的线性回归预测与越界时间计算，不包含任何行业规则。

### 输入

- 数据 CSV、时间列、属性列（数值）；
- 可选的批次列；`model` 为 `pooled`（共同斜率，各批次截距不同）或 `separate`（各批次单独拟合）；
- 接受标准（规格限）与方向：`decreasing`（属性随时间下降，检查下界）或 `increasing`（检查上界）；
- 单侧置信水平，默认 0.95，允许调整（与 ADR-0072 的参数策略一致）。

### 计算

- 线性模型拟合（由 R 完成）；
- 对给定时间 t，预测均值的单侧置信界限为 ŷ(t) ∓ t(1−α, df)·s·√(1/n + (t−t̄)²/Sxx)；
- 求解置信界限与接受标准相交的时间点（R 基础包中的 `uniroot`）；
- 若交点超出数据的最大时间点，返回标志 `extrapolated`，表示外推，由报告模板要求用户说明。

### 输出

- 系数、标准误、残差自由度、残差标准差 s、t 分位数、置信水平、方向、接受标准；
- 每个批次（或合并模型）的有效期，以及交点是否外推；
- 来源记录：算法名与版本、R 版本、程序与输入的哈希、所有参数与其来源（默认或调整）。

## 范围

包含：线性模型（时间为数值），pooled 与 separate 两种形式，单侧界限，外推标志。

不包含：

- 非线性或分段模型；
- 双侧界限（需要另立 ADR，并与指南对照）；
- 批次可合并性的判断本身（由 `statistics_ancova` 提供，ADR-0073）；
- 任何行业专用的接受标准或报告规则。

## 验证要求

- 参考数值：用 statsmodels 与 SciPy 对固定数据计算预测置信界限与越界时间，R 结果在 1e-9 相对容差内比对。
- 交点求解的误差上限在结果中报告。
- 所有 R 相关测试只在 CI 中执行（固定版本 R 4.6.0）。

## 未决事项

- **指南原文核对。** 单侧 95% 界限、外推的判定，需要方法或质量人员对照 ICH Q1E 与 CDE 指导原则原文确认。本 ADR 没有核实指南原文。
- **pooled 的定义。** 本 ADR 把 pooled 定义为"共同斜率、批次截距"。是否在斜率不可合并时禁止使用 pooled，由 Suite 的领域规则决定，Foundation 不强制。
- **f2 的计算路径仍未决**，不在本 ADR 范围内。

## 与其他 ADR 的关系

- ADR-0054、ADR-0055：统计引擎与数值溯源；本 ADR 沿用其结果文件格式。
- ADR-0072：Suite 首批范围；有效期功能依赖本 ADR。
- ADR-0073：斜率与截距的比较，用于 poolability 判断。
