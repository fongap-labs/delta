# ADR-0076：内置 Skill 的确定性评估

状态：**已接受**（所有者，2026-10-26，同意按建议执行）。

## 背景

- 内置 Skill（ADR-0066、ADR-0068、ADR-0069 等）的验收目前依赖一次性的人工检查和单元测试中的字符串断言。
- DeepSeek Harness 的确定性评估思路（结果、合规、过程三个维度，不使用 LLM 作为评审）可以把验收自动化，且不引入新依赖。

## 决定

1. **不新增顶层目录。** 评估写在 `crates/delta-core/src/skills.rs` 及其相邻的测试模块中，与现有内置 Skill 测试放在一起。
2. **三个维度，都是确定性检查：**
   - **结果：** Skill 必须包含的章节与必须点名的工具（每个点名的工具都必须真实存在于产品的工具表中）。
   - **合规：** 禁止出现的表述，例如"无需批准"（Skill 不得声称绕过审批）。
   - **过程：** 步骤数量在约定范围内；每个步骤有编号。
3. **不评估模型输出。** 确定性评估只检查 Skill 文本本身；模型实际按 Skill 行动的质量不在本 ADR 范围内。
4. **不采用过程分数的加权与打折。** 只做通过或不通过的检查，结果可解释。

## 未验证事项

- 评估只能发现文本层面的问题，不能证明模型会正确执行 Skill。

## 实现记录

- 测试 `every_built_in_skill_passes_the_deterministic_checks`（`skills.rs`）对每个内置技能执行三类检查：结果（点名的工具都是产品注册的工具）、合规（不含"无需批准"等表述）、过程（有编号步骤，并说明做不到的事）。
- 没有引入新目录或依赖，没有使用 LLM 评审。
