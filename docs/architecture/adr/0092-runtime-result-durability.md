# ADR-0092：完整工具结果与压缩状态的可靠提交

状态：提议（本 PR 实现，待评审）

## 问题

长文档和大型表格的工具结果超过内联上限后，通用处理只留下预览，无法保证其余内容可再次读取。压缩摘要则可能仅在内存中生效，保存失败后重启会使用不同上下文。

## 决定

1. Rust Runtime 在裁剪超限结果之前，将工具返回的完整 JSON 保存到既有 `core.db` 的 `tool_outputs` 表。记录包含随机引用 ID、会话、工作区、运行、工具调用、内容及 SHA-256；不成为正式 Artifact，也不授予 Source/Citation 身份。
2. 会话、事件流和幂等重放记录携带预览及 `output_ref`。预览最多取原始 JSON 的 16 KiB，并保持 UTF-8 边界；128 KiB 的内联触发阈值不变。工具结果中已有的图片路径与 `ok` 字段继续保留。
3. 新增受现有 CapabilityHost、Policy 和执行门禁管理的只读工具 `read_tool_output`。身份来自 Runtime 生成的 Job；调用参数不能指定其他会话或工作区。每页最多 16 KiB 原始 JSON 文本，使用 UTF-8 字节偏移；返回下一页偏移、总长度、哈希和原始调用身份。
4. 完整结果必须先成功保存，才能发布引用。执行已经发生而保存失败时，沿用现有 `Uncertain` 状态，禁止自动重放副作用；不声称结果已完整保留。
5. 结果随会话保留，删除会话行时由同一数据库事务中的外键级联删除。审计账本继续只记录摘要，不复制完整内容。旧会话和旧的截断结果保持可读，但无法补回历史上已经丢弃的内容。
6. 压缩摘要、边界和锚点继续使用已有会话字段，以一条 SQLite 更新原子保存。更新零行视为失败。只有更新成功才替换内存投影并发送 `Compacted`；失败时保留上一份投影。无持久化 Authority 的测试宿主仍允许纯内存压缩。
7. 扩展清单先准备并校验全部注册，在 Registry 的一次写锁内验证冲突并提交；任一项失败，不发布该清单的任何注册，也不影响已有注册。

## 边界与兼容性

本变更不迁移 Runtime、审批或幂等权威，不引入外部框架。新增结果表与工具不改变 Worker ABI；旧结果不含 `output_ref` 时继续按原形状处理。数据库表是增量添加，旧版本不能主动清理新表中的结果，不建议写入新结果后降级运行。

第一阶段不承诺完整请求重建、无损语义摘要、动态工具选择或扩展热卸载。摘要输入保留策略和完整 token 预算另行处理。

## 验证

- 清单后项非法、同批重复名或与已注册工具冲突时，目录保持原样；合法多项全部可见。
- 多页中文及 emoji 能重建完整 JSON；不同会话或工作区不可读取；内容损坏拒绝返回；删除会话后不可读取。
- 大结果重放保留相同引用；存储失败进入不确定状态。
- 压缩保存错误不改变现有内存投影和已存状态；不存在的会话拒绝保存；既有恢复测试继续验证锚点一致。

## 代价

完整结果增加本地存储用量。第一版每次分页先读取完整文本并校验哈希，适合现有受限工具输出规模；后续依据真实数据量评估流式读取和保留策略。删除行不等同于对存储介质安全擦除。


## 上下文预算的后续实现（2026-11）

后续 Runtime 预算改进沿用本 ADR 的持久化 Authority：压缩只替换模型请求中的旧消息投影，不删除原始对话、审批、幂等或完整工具结果。上下文预算按实际出站消息、系统提示、工具定义、工具调用与结果估算；取用户配置预算与已知模型窗口中的较小值。在超限时先压缩安全的旧前缀，保留未配对的工具调用、最近对话及必要恢复锚点；若剩余上下文仍超限则拒绝模型请求，不绕开约束。

摘要生成沿用已配置的模型 Authority 与出境门禁。摘要和边界仍在同一条 SQLite 更新中提交；成功后才更新内存并发布事件。旧会话缺少摘要锚点时继续按未压缩处理。估算不声称精确，媒体与提供商私有 token 规则仍存在误差，发送前附加安全余量。

## 工具结果分级输出（2026-11）

在原有完整结果存储与 `read_tool_output` 能力基础上，工具结果按 UTF-8 JSON 字节数分级：不超过 16 KiB 时原样内联；16～128 KiB 提取约 2 KiB 的首尾预览；超过 128 KiB 提取约 4 KiB 的首尾预览。分级结果仍携带结构形状、关键状态和现有图片路径，完整 JSON 先写入同一 `tool_outputs` 表并获得可校验的 `output_ref`，随后才写入对话及幂等重放记录。分页读取工具的返回值禁止再次外置，以免产生递归引用；旧记录仍按既有形状读取。原始完整结果不直接进入模型上下文。

此策略不会替代运行时的 token 预算与摘要压缩。新存储行为会增加 16～128 KiB 工具结果的本地占用；失败仍遵循既有不确定结果和禁止自动重放的规则。
